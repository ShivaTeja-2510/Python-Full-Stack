SETS

Introduction to Sets
A set is an unordered, mutable collection used to store unique values.
Sets are created using set() function.
Sets automatically remove duplicate values.

numbers = {10, 20, 30}
names = {"Ravi", "Teja", "Ankit"}
mixed = {10, "Python", 5.5, True}
print(numbers)

SET PROPERTIES

Property Description
Unordered Elements do not maintain insertion order
Mutable Elements can be added and removed
Unindexed Elements cannot be accessed using index positions
Iterable Can iterate through elements using loops
Unique Elements Duplicate values are automatically removed
Heterogeneous Can store different datatypes
Dynamic Size Elements can be added or removed anytime
Supports Nested Immutable
Objects

Can contain tuples and frozensets

Mutable Objects Not Allowed Lists, sets, and dictionaries cannot be stored directly

SET OPERATIONS

1. Membership Operators
Checks whether an element exists.

data = {10, 20, 30}
print(20 in data) # True
print(100 not in data) # True

2. Union
Combines all unique elements from both sets.

a = {1, 2, 3}
b = {3, 4, 5}
print(a | b) # {1, 2, 3, 4, 5}

Python

Python

Python
3. Intersection
Returns common elements.

a = {1, 2, 3}
b = {2, 3, 4}
print(a & b) # {2, 3}

4. Difference
Returns elements present in the first set but not second.

a = {1, 2, 3}
b = {2, 3, 4}
print(a - b) # {1}

5. Symmetric Difference
Returns elements present in either set but not both.

a = {1, 2, 3}
b = {2, 3, 4}
print(a ^ b) # {1, 4}

6. Subset
Checks whether all elements of one set exist in another.

a = {1, 2}
b = {1, 2, 3, 4}
print(a <= b) # True

Python
7. Superset
Checks whether a set contains all elements of another set.

a = {1, 2, 3, 4}
b = {1, 2}
print(a >= b) # True

FROZENSET
A frozenset is an immutable version of a set.
Once created, elements cannot be added or removed.

data = frozenset({10, 20, 30})
print(data)

Properties of frozenset:
● Immutable
● Unordered
● Unique Elements
● Hashable
● Can be used inside sets and as dictionary keys

WHY USE SETS?
● Remove duplicate values
● Perform mathematical set operations
● Fast membership checking
● Store unique items
● Compare collections efficiently
Examples:

unique_ids = {101, 102, 103}
available_sizes = {"S", "M", "L", "XL"}
visited_pages = {"Home", "Products", "Cart"}

DICTIONARIES

Introduction to Dictionaries
A dictionary is a collection of key-value pairs used to store related data.
Dictionaries are created using curly braces { } or the dict() function.

student = {
"id": 101,
"name": "Ravi",
"course": "Python"
}

DICTIONARY PROPERTIES

Property Description
Ordered Maintains insertion order (Python 3.7+)
Mutable Items can be added, removed, and modified
Indexed by Keys Values are accessed using keys, not numeric indexes
Iterable Can iterate through keys, values, and items
Unique Keys Duplicate keys are not allowed
Duplicate Values Allowed Multiple keys can have the same value
Heterogeneous Can store different datatypes
Dynamic Size Can grow or shrink during execution
Nested Structures Supported Can contain lists, tuples, sets, dictionaries, etc.
Keys Must Be Hashable Keys must be immutable/hashable objects

1. Accessing Values
Values are accessed using keys.

"name": "Ravi",
"age": 22
}

}

NESTED DICTIONARIES
A dictionary inside another dictionary is called a nested dictionary.

students = {
"s1": {"name": "Ravi", "age": 22 },
"s2": {"name": "Teja","age": 21}
}
print(students["s1"]["name"]) # Ravi

MUTABLE VALUES INSIDE DICTIONARIES
Dictionary values can be mutable objects.

student = {
"marks": [90, 85, 88]
}
student["marks"].append(95)
print(student)
{'marks': [90, 85, 88, 95]}
