n = int(input("Enter number: "))

factors = []

for i in range(1, int(n ** 0.5) + 1):
    if n % i == 0:
        factors.append(i)

        if i != n // i:
            factors.append(n // i)

factors.sort()

print("Factors:", *factors)

N=6

9. Check if a number is prime

n = int(input("Enter number: "))

if n < 2:
    print("Not a prime number")
else:
    is_prime = True

    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            is_prime = False
            break

    if is_prime:
        print("Prime number")
    else:
        print("Not a prime number")

 Input:
Enter number: 7
Output:
Prime number

Quick Trainer Review
There are a few duplicate/repeated questions in this set:
Questions
Observation
4 & 15
Both are factorial
6 & 23
Both find maximum/largest element
10, 30 & 37
All are essentially the same star triangle
4, 15 & 36
All involve factorial; Q36 is unclear
10 & 26
Both use nested loops for patterns, but Q26 is a number pattern
20 & 32
Both deal with prime numbers; Q20 generates them, Q32 counts them

For freshers, I would especially keep 1–9 first, then 11–19, and only after students understand nested loops and basic logic move to 20–38.
